# 🎓 ShadowFox AI Student Assistant

A beginner-friendly AI-powered student utility app built using Python, Streamlit, and Groq API.

## Features

- 📝 Note Summarizer
- ❓ Quiz Generator
- 💡 Concept Explainer

## Technologies Used

- Python
- Streamlit
- Groq API
- python-dotenv
